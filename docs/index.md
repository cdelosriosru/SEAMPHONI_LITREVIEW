# Ecosystem services valuation in ocean contexts — search progress

This page tracks the ongoing literature search for the SEAMPHONI ecosystem
services valuation review. Each entry below documents one round of
querying (via the OpenAlex API), the resulting counts/tables, and running
commentary on what they suggest. Here are also listed the innitial search terms

## Search terms

Queries are built by combining terms from these groups (an ecosystem
services group AND an ocean-context group, optionally AND a management
group) — see `code/OpenAlex_search_new_counts.py` for the exact query
logic.

[SEE THE Search Strategy summary and purpose here](search_strategy.md)
